# Experiment record

Stockjection has run **223 numbered experiments** so far. Each one had its pass / fail rule written down before it ran,
and the verdict was recorded whatever it was.

| Verdict | Experiments |
|---|---|
| Passed its rule | 44 |
| Failed its rule | 152 |
| Descriptive, partial or superseded | 27 |

Most ideas fail. That is the point of writing the rule first: only changes that pass, and then survive a live shadow test,
reach the published model.

The detailed log (what each experiment changed) is kept private, because it is the recipe. Independent researchers can ask
for a verification session through the repository's issues.
